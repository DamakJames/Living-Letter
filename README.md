## 📖 About Living Letters
**Living Letters** is a Christ-centered media and digital discipleship platform founded by **Pastor Solomon Amao**. The ministry's mandate is to equip believers across the globe to understand Scripture, mature spiritually, and live as authentic epistles inscribed by the Holy Spirit—known and read by all.

### Core Discipleship Pillars
1. **Replicate:** The life and character of Christ through the grace of the Holy Spirit.
2. **Rule:** In spiritual authority, truth, and righteousness through the Gospel of the Son.
3. **Reflect:** The holiness, wisdom, and glory of the Father in society and culture.

## 🎨 Design System & Visual Identity
- **Primary Color:** Deep Midnight Navy (`#0F172A`)
- **Secondary Color:** Royal Sapphire Blue (`#2563EB`)
- **Accent Color:** Warm Kingdom Gold (`#D97706` / `#F59E0B`)
- **Neutral Light:** Crisp Clean Slate (`#F8FAFC`, `#F1F5F9`)
- **Typography:**
  - Headings & Branding: `Plus Jakarta Sans`, 700 / 800 weight
  - Scripture Accents: `Playfair Display` / `Cinzel` serif
  - Body Copy: `Inter` / `Segoe UI`, 400 / 500 weight (1.75 line-height)
- **UI Components:** Glassmorphism navigation bar, responsive mobile menu drawer, custom SVG iconography, interactive audio players, and responsive card grids.

## 🚀 How to Run & Preview Locally

Because Living Letters is built with modern, standard-compliant HTML5, CSS3, and ES6 JavaScript with zero external build dependencies:

1. **Option A (Python Simple Server):**
   ```bash
   python3 -m http.server 8000
   ```
   Open `http://localhost:8000` in any web browser.

2. **Option B (Direct Browser File):**
   Simply open `index.html` in your browser of choice.
